# Friend Auto Add Tool (3DS)

Застосунок для Nintendo 3DS, який додає в друзі всіх учасників спільної бази кодів ([t.me/n3ds_ua](https://t.me/n3ds_ua)).
Двоє людей запускають його, кожен має код іншого в базі — і вони стають друзями. Учасників може бути скільки завгодно, у межах 100 друзів, які вміщує консоль.

Якщо людина ще не додала ваш код, запис лишається **заявкою** (у системному «Списку друзів» — «тимчасово зареєстрований»). Заявка лежить на сервері Pretendo; щойно людина додасть вас, ви станете друзями — консоль побачить це при наступному виході в інтернет.

## Що потрібно

- Nintendo 3DS / 2DS / New 3DS з **Luma3DS** ([3ds.hacks.guide](https://3ds.hacks.guide/))
- **Pretendo Network** через Nimbus, перемкнений на Pretendo: сервери Nintendo Network для 3DS вимкнені з квітня 2024
- обліковий запис друзів на консолі (раз відкрийте «Список друзів» у меню HOME)
- Wi-Fi

## Встановлення

Скопіюйте `FriendAutoAddTool-<версія>.cia` на SD-карту й встановіть через FBI. Потрібна саме CIA: доступ до списку друзів (`frd:a`) дає лише вона, а не `.3dsx`.

Застосунок має той самий ідентифікатор, що й попередня збірка автора ідеї (`0xFE040`), тож встановлення замінить її в меню HOME.

## Як користуватися

1. **Перевірка консолі** — перший екран: Luma, доступ до друзів, ваш код, Nimbus/Pretendo, Wi-Fi, вхід у сервіс друзів, місця у списку, SD-карта, база, заряд. Якщо чогось бракує, внизу написано, що зробити.
2. **Оновити базу** — завантажує `friend_code.txt` з цього репозиторію на SD-карту (`sdmc:/FriendAutoAddTool/`). Якщо завантаження обірвалось або файл порожній, стара база лишається.
3. **Додати друзів** — додає коди з бази, яких ще немає у списку. Свій код і тих, хто вже у списку, пропускає. Коли місць менше, ніж кодів, першими йдуть **новіші** (нижчі у файлі). Між кодами пауза в 1 секунду; `B` зупиняє після поточного коду.
4. **Журнал** — що зроблено з кожним кодом: «взаємний», «заявка», «пропущено», «помилка», «тепер взаємний». Повний журнал — `sdmc:/FriendAutoAddTool/log.txt`.
5. **Видалити друзів** — «Тільки коди з бази» (справжні друзі лишаються) або «Усіх друзів», з підтвердженням.

Керування: D-Pad / Circle Pad — вибір кнопки, `A` — дія, `B` — назад, `X` — оновити базу, `Y` — журнал, `START` — вихід. Усе так само працює стилусом.
`L` + `R` + `Y` на головному екрані — службовий екран зі станом кожного друга (для перевірки, як сервер записав заявку).

## База кодів

[`db/friend_code.txt`](db/friend_code.txt), один код у рядку:

```
# коментар
1234-5678-9012|нік
2204 1225 1663
```

- ім'я після `|` необов'язкове, до 10 символів — так заявка підписана у списку друзів, поки людина не додасть вас (тоді система покаже її власний нік);
- пробіли й дефіси в коді не важливі; код із хибною контрольною сумою пропускається;
- **нові коди дописуйте в кінець файлу**;
- файл — до 64 КБ і до 1000 кодів.

Застосунок читає файл за адресою з `app/source/net.h` (`DB_URL`); якщо репозиторій переїде, зміниться лише вона.

## Збірка

Потрібні Docker (образ `devkitpro/devkitarm`), а для CIA — `makerom` і `bannertool` (шляхи — у `Makefile`, `MAKEROM=`/`BANNERTOOL=`). Своя заставка при запуску підписується ключем із коду меню HOME (`HOME_MENU_CODE=`, дамп у репо 3DS UA); без нього CIA лишається зі стандартною заставкою homebrew.

```
make test    # host-тести: коди друзів, парсер бази, черга додавання
make app     # app/FriendAutoAddTool.3dsx
make cia     # FriendAutoAddTool-<версія>.cia
make venv fonts art   # лише якщо міняються шрифти чи іконка
```

Інтерфейс — за макетом <https://claude.ai/artifact/2iZeEnFSEeJkaQFKbizkto>, у стилі [3DS UA](https://github.com/BolgarMaxym97/3ds-ua). Шрифт Nunito — OFL (`app/assets/fonts/OFL.txt`).
